# Smart Library System

This is my Python final project for managing a library using Object-Oriented Programming (OOP).

## What the project does:
- Manages books (add, remove, search, and view).
- Allows students and teachers to borrow and return books.
- Saves all book data automatically in a text file so it doesn't get lost when the program closes.
- Includes error handling so the program doesn't crash if someone enters a wrong input.

## How to run it:
1. Open the project folder in VS Code or your terminal.
2. Run the main file by typing:
   ```bash
   python main.py
